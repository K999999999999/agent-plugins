# Spec 与工作项约定发现

这是 `setup-engineering-workflow` 初始化时使用的只读检查清单，不指定某个固定 Tracker、目录、文件模板或状态字段。

## 探索顺序

- 先读取 Agent instructions、README、贡献指南和工程文档；
- 检查仓库中已有的 Spec、Ticket、Issue、计划、决策和验收记录；
- 确认它们存储于本地文件、外部 Tracker，还是两者都有；
- 查看现有记录的路径、格式、状态、依赖关系、Owner、评审和归档方式；
- 判断当前规则是否能支持从需求到实现、验证与交付的追踪；
- 发现冲突时列出证据和影响，等待用户决定优先级。

## 提出配置建议

- 足够的项目约定无需重建；
- 缺少必要约定时，根据项目实际工作方式提出最小选择，而不是直接采用固定目录或状态集合；
- 分清工作项跟踪与需求澄清、工作流路由、实现授权和发布授权；
- 外部 Tracker、PR 或远程同步不属于默认初始化范围；
- 写入任何新约定前，说明文件路径和内容，并等待用户确认。
